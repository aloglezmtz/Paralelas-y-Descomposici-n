El corazón del código

def sumar_segmento(segmento):
    return sum(segmento)                     # tarea independiente

def dividir(lista, partes=4):
    tam = len(lista) // partes
    return [lista[i*tam:(i+1)*tam] for i in range(partes)]

with multiprocessing.Pool(4) as pool:
    parciales = pool.map(sumar_segmento, dividir(lista))
total = sum(parciales)                       # combinar resultados

Práctica 6 · Programación Paralela y Concurrente · CUCEI. Modelo de la animación: t_seq = n·c; t_par = c₀ + n·e + ⌈4/núcleos⌉·(n/4)·c, con c = ns por elemento (en carga pesada, ns), c₀ = ms (crear el pool) y e = ns por elemento (serializar y enviar). Con pocos núcleos los 4 procesos se turnan; con 4 o más corren a la vez.
